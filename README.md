# Website Profile Cá Nhân

> Website portfolio cá nhân dùng để giới thiệu bản thân, kỹ năng và chia sẻ blog.

---

## Giới thiệu
Đây là một **website** được xây dựng bằng HTML, CSS và JavaScript với mục đích: giới thiệu thông tin cá nhân, trình bày kỹ năng & công nghệ, chia sẻ các bài blog và làm portfolio khi ứng tuyển thực tập / công việc.



---

## Tính năng
✨ Giao diện hiện đại, tối giản • 📱 Responsive (mobile & desktop) • 📖 Trang blog riêng • 🎨 Hiệu ứng mượt mà

---

## Công nghệ sử dụng
HTML5 • CSS3 (Flexbox, Grid) • JavaScript (Vanilla)
